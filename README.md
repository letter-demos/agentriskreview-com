# Agent Risk Review

Agent Risk Review provides independent risk evaluation and compliance reporting services for insurance agents, brokers, and agencies seeking to strengthen their underwriting credibility and demonstrate accountability to carriers and clients alike.

A demo site: https://agentriskreview.com

## Glossary

Glossary terms live in `content/glossary.json`. After editing it, run `node scripts/build-glossary.mjs` to regenerate the pages in `glossary/`.
